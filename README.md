# React CRUD
I made this to learn about CRUD on Reactjs, and get used it with the tech, cuz I was used to HTML/CSS <br />
So, the project can work on your machine if you run, after you download the project, with nodejs installed, you get the dependencies first with
```
npm install
```
To run the app:
```
npm run dev
```
